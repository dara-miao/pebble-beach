# Pebble Beach

See how a shot plays out from this lie, on Pebble. Preview is the same flight as Hit.

```bash
npm install
npm run dev
```

```bash
npm test
npm run build
```

Opens on hole 1.

Type a shot — `driver 250 fade`, `pw 80`, `putt 24 ft`. Watch the preview, then Hit. The ball stays where it lands. Leftover updates. Next shot is from that lie.

Click the turf to aim. Default camera is Stand (behind the ball). Arrow keys change holes. `r` resets the hole. Wind is on the HUD. New round goes back to 1. The card is 18.

**First try.** Hole 1 is the Lodge opener — hit a drive, play the leftover. Hole 7 is the downhill par 3: `8 iron 100` holds the green but the miss envelope finds bunker; `pw 50` is the ocean miss.

Hills are USGS NED, not invented. Thin OSM holes get a repaired green, tee, or fairway so the full card plays.
